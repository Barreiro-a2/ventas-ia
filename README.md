# 🤖 Ventas-IA

Un asistente inteligente desarrollado en Python diseñado para automatizar y optimizar el proceso de ventas. Este sistema procesa consultas de clientes y ofrece respuestas automáticas sobre servicios, promociones y soporte técnico.

## 🚀 Características
- **Procesamiento de Consultas:** Identifica palabras clave como "internet" o "promoción".
- **Respuestas Inteligentes:** Respuestas estructuradas para mejorar la conversión de ventas.
- **Arquitectura Escalable:** Preparado para integrarse con APIs de IA (como OpenAI o Gemini).
